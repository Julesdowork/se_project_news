# News Explorer

A React app where users can search for news articles. My TripleTen final project.

## Description

News Explorer is my chosen project for the final sprint in the TripleTen Software Engineering bootcamp. It is a React app where users can search for news articles by keywords entered into the site search bar, and displays the relevant articles over the last week below that. Users will also be able to create an account on the site in order to save articles to their personal page. The app will have two routes: the main page and one where they can view their saved articles. The latter route will be protected, and only logged in users will be able to access it. The Figma design was supplied by the TripleTen team, and gives specifications for desktop, tablet, and mobile layouts and styling.

The project is arranged using BEM methodology for both its folder structure and when naming the CSS classes. Styling for each React component is placed in the same folder as its corresponding React functionality. Articles will be displayed in cards which each have a button for registered users to save the article for later. The app uses child Modal components, which are derived from a custom-made base Modal component, to handle user registration and sign in. There will be a separate project for the back-end API for this app, but until then we will be using dummy data for those features.
